# 消费者端就近约束

适用于本目录及其子目录；同时遵守[全仓约定](../../agent.md)。本轮已获消费者端模拟前端开发授权；不可把模拟流程声称为可上线的真实订单/支付能力。

- 开始修改前阅读[消费者需求](../../docs/consumer/需求.md)、[原型](../../docs/consumer/原型.md)、[接口能力清单](../../docs/consumer/接口清单.md)和[共通规则](../../docs/common/业务规则与跨端流程.md)。原型路由不是现有代码；接口清单不是正式契约。
- 后续获准编码时，预约占用应考虑半小时排班、服务时长与前后缓冲；超服务半径允许下单且服务者可拒单。涉及下单、优惠、上门费、支付/退款和状态展示的实际判定点按全仓约定写就近约束注释，标明源文档及待确认事项。
- 客户端不得自行决定最终可约性、支付结果、退款、抽成或订单状态；服务端权威校验方案尚待设计。当前 JSON 演示仓储不得作为正式接口契约或实际财务依据。
