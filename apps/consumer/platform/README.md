# 平台适配边界规划

当前工程规划面向微信小程序，未来在此集中处理小程序登录授权、定位权限、支付唤起、上传/媒体及本地存储；目前不创建 Android/iOS 适配工程，但不删减原始 PRD 的兼容要求或微信/支付宝支付 P0。上层功能模块不应直接假定回调、渠道或权限行为。具体 API、权限声明、跨平台渠道方案与配置须经产品/技术确认及正式服务端契约约定，不创建模拟实现。

尤其是支付：渠道回跳只触发结果查询，最终成功/失败以服务端核实的状态为准；定位失败须允许用户手动选址，超服务半径不能在适配层被强制禁止下单。平台适配层不计算抽成、退款或结算。

更多约束见[骨架设计](../ARCHITECTURE.md)与[共通规则](../../../docs/common/业务规则与跨端流程.md)。本目录目前只有文档，没有配置或源码。
