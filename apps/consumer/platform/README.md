# 平台适配边界规划

当前工程面向微信小程序。真实登录授权、定位权限、支付唤起、上传/媒体等平台适配尚未实现；本地存储仅由模拟仓储用于开发演示。此处后续集中平台适配；目前不创建 Android/iOS 工程，但不删减原始 PRD 的兼容要求或微信/支付宝支付 P0。上层功能模块不应直接假定回调、渠道或权限行为。具体 API、权限声明、跨平台渠道方案与配置须经产品/技术确认及正式服务端契约约定。

尤其是支付：渠道回跳只触发结果查询，最终成功/失败以服务端核实的状态为准；定位失败须允许用户手动选址，超服务半径不能在适配层被强制禁止下单。平台适配层不计算抽成、退款或结算。

更多约束见[骨架设计](../ARCHITECTURE.md)与[共通规则](../../../docs/common/业务规则与跨端流程.md)。
