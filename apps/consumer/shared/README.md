# 端内共享能力规划

未来仅存放**与具体业务模块无关**、可在消费者端复用的能力，例如通用展示组件、加载/错误/空态表现、数据格式化及请求适配的公共约定；不把预约、退款、抽成等业务决策沉入“工具函数”。组件 API、状态方案和目录层级在正式技术选型及页面实现时确定。

如需 uview-plus 包装层，只在有平台兼容性或复用需求时引入，避免直接依赖某一版本的私有行为。接口错误、鉴权失效与重试的统一处理依赖待确认的正式协议；不能在这里臆造错误码。

更多约束见[骨架设计](../ARCHITECTURE.md)与[全仓约定](../../../agent.md)。本目录目前只有文档，没有源码。
