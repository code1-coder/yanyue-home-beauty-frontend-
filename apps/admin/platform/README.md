# Web 平台适配边界规划

此层只规划浏览器及外部平台能力边界，例如文件上传/图片预览、授权下载/导出、会话失效反馈、支付/打款凭证展示及浏览器兼容处理。管理后台交付 Web，原始 PRD 要求管理后台 Chrome 兼容；不把服务端支付回调、短信推送、打款或数据库访问放进浏览器适配层。

财务对账、退款和提现打款可能涉及上传/下载，但**文件动作完成不等于资金状态变更成功**；前端须取得正式接口权威结果。敏感证件与收款账户的预览、导出和缓存要按权限与脱敏约束处理。上传规则、文件大小、格式、错误码和凭证流程尚待正式契约，不能据此建立模拟实现。

具体浏览器 API、图表/富文本/下载库和支付渠道对接方式在授权建工程后验证，不在 GitHub 文档写入本机配置、密钥或未确认的依赖版本。见[骨架设计](../ARCHITECTURE.md)与[共通规则](../../../docs/common/业务规则与跨端流程.md)。
