# 应用壳与导航规划

> 来源：[原始原型 §一、§四](../../../docs/原型整体结构.md)、[后台需求 §5.3.16](../../../docs/admin/需求.md)。当前只有说明文档，不存在路由、菜单配置或权限代码。

未来 app 负责 Web 应用入口、左侧菜单与顶部栏布局、登录后的导航组合、页面挂载和会话状态展示；具体路由名与层级由原型交互和工程方案确认。后台原型没有建议 URL，菜单树也不等于页面路由表，不在这里捏造路径。

按模块向 app 暴露入口信息，而非让 app 了解审核、财务、商城模块的内部表单和状态；页面可由不同菜单或待办抵达同一业务能力。是否懒加载、如何保存筛选条件、页面刷新和登录过期返回路径，需在实际工程中验证。

**权限边界**：菜单/按钮显隐仅改善体验，不能作为授权依据。角色、菜单和数据权限属于 PRD P0，服务端须对每次读写及城市/数据范围进行最终校验；前端未获权限时不展示敏感信息，收到拒绝后不将本地显示视为授权。审核与打款操作还需防重复提交、状态刷新和服务端审计，具体契约待设计。

分层与待确认事项见[骨架设计](../ARCHITECTURE.md)；本目录不是已初始化的 Vue 应用。
