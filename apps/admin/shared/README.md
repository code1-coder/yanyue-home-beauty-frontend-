# 端内共享能力规划

未来只承载后台多业务模块都需要、且不包含特定业务判定的基础能力：通用表格/筛选/分页/空态、表单反馈、格式化、错误展示、可复用的 Element Plus 适配组件及通用请求处理。具体组件和状态方案待工程验证后决定，避免为抽象而抽象；Vue 3 的页面入口保持薄、组件职责聚焦、数据流明确。

金额、提现门槛、抽成优先级、服务订单/商城订单状态、审核可操作项和城市数据范围**不属于**通用组件的最终判定；它们必须遵守业务模块及服务端正式契约。导出与日志不能默认包含身份证、健康证、收款账户、手机号等敏感资料；字段、权限、脱敏、审计由正式方案确定。不虚构错误码、接口字段或跨端共享运行时代码。
