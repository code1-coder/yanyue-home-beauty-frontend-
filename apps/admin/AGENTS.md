# 管理后台就近约束

适用于本目录及其未来子目录；同时遵守[全仓约定](../../agent.md)。当前仅有文档，不得据此开始编码或初始化空工程。

- 开始修改前阅读[后台需求](../../docs/admin/需求.md)、[原型](../../docs/admin/原型.md)、[接口能力清单](../../docs/admin/接口清单.md)和[共通规则](../../docs/common/业务规则与跨端流程.md)。原型路由不是现有代码；接口清单不是正式契约。
- 后续获准编码时，在审核、订单改派/退款、抽成快照与冲正、结算、提现审核打款、角色/数据权限的实际判定点写就近约束注释，标明源文档及待确认事项；操作留痕、支付渠道回调和对账不能由 UI 单独裁决。
- 当前 Web 后台工程规划采用 Vue 3 + Element Plus；原始原型的 Element UI 组件示意和业务页面均保留为产品参考，组件 API 需适配验证。具体构建工具、服务端方案和接口契约待确认。未授权前不创建页面、接口桩、配置或测试代码。
