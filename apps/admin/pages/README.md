# 页面与导航入口规划

> 来源：[原始原型 §四页面清单](../../../docs/原型整体结构.md)，完整要素见[后台原型摘录](../../../docs/admin/原型.md)。原文列出 **34 行页面/交互条目，但没有建议 URL**；下列序号照原文，不代表 34 个已注册路由或既定文件名。

未来 pages 只组合列表、筛选、详情和弹窗等视图，业务动作由[features](../features/README.md)提供，导航/布局由[app](../app/README.md)管理；跨模块业务状态及钱款不能在页面计算为最终结果。

| 原型序号 | 所属领域 | 原文页面/交互条目 |
| --- | --- | --- |
| 1–2 | 登录/工作台 | 登录、工作台 |
| 3–6 | 审核中心 | 服务者入驻审核、资质审核详情、提现审核、退款/售后审核 |
| 7 | 用户管理 | 消费者列表 |
| 8–10 | 服务者管理 | 美容师列表、美容师详情、独立抽成设置 |
| 11–12 | 项目管理 | 项目分类、项目列表 |
| 13–14 | 服务订单 | 订单列表、订单详情 |
| 15 | 排班调度 | 排班查看 |
| 16 | 抽成管理 | 抽成模板 |
| 17–20 | 财务管理 | 支付流水、结算单、提现记录、对账 |
| 21–23 | 营销管理 | 优惠券、活动、Banner/推荐位 |
| 24–25 | 内容管理 | 发现页内容、评论审核 |
| 26 | 评价管理 | 评价管理 |
| 27–29 | 工具商城 | 商品管理、商城订单、商城售后 |
| 30 | 消息通知 | 推送/短信 |
| 31 | 数据统计 | 数据统计 |
| 32–34 | 系统设置 | 角色权限、操作日志、系统设置 |

原型信息架构还列出消费者详情、奖惩/禁用、资质到期提醒、改派、冲突处理、退款记录、库存/物流、投诉/申诉、站内信等子项，但**未逐项赋独立页面清单行**；保留业务能力，不能据此补造既定 URL 或宣称功能不存在。独立抽成设置的原型组件是弹窗，设置页可含多个 Tab；实际采用页面、弹窗或复用详情页须交互评审。原型 Element UI 组件只是表现建议，迁移 Vue 3 + Element Plus 时验证 API，不机械照搬。

PRD 的 P0/P1/P2 是功能优先级，原型第一/二/三阶段是交付节奏，尤其角色权限与财务规则 P0 不因“系统精细化”第三阶段而降级。页面入口和权限展示边界见[骨架设计](../ARCHITECTURE.md)。目前没有页面或路由代码。
