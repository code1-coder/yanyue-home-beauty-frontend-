# 服务者端小程序 UI 视觉方案

> 依据[服务者端原型](../../docs/provider/原型.md)及本轮视觉要求。仅定义呈现层，不改变接口、页面路径、字段与业务状态；实际页面仍使用本地 JSON 模拟数据。以手机竖屏、750rpx 设计宽度为基准，以下 px 数值在源码中按 1px = 2rpx 对应。

## 基础令牌

| 用途 | 色值 / 规格 | 组件说明 |
| --- | --- | --- |
| 主色 | `#386C5D` | 主按钮、选中 Tab、重点标题与线性图标 |
| 辅助色 | `#EAF3EE` | 身份区、占用时段、轻提示与标签底色 |
| 金额与提醒 | `#386C5D` | 收入、价格、待办数字；不用于大面积背景 |
| 页面 / 卡片 | `#F9F7F3` / `#FFFFFF` | 内容卡片用 `0 4px 20px rgba(65,100,87,.07)` 轻阴影 |
| 文字 | `#2D2D2D` / `#666666` / `#999999` | 标题 / 正文 / 辅助；分隔线 `#EEEEEE` |
| 状态 | 待接 `#FFEBD8`、服务中 `#E6F2EF`、完成 `#E8F3FF`、取消 `#F4F4F4` | 小胶囊背景，保留文字说明，不单靠颜色区分 |
| 字号 | 18 / 16 / 14 / 12px | 页面标题 / 模块标题 / 正文 / 辅助，正文行高 1.5 |

## 页面布局

| 页面 | 自上而下的布局及组件 |
| --- | --- |
| 工作台 | 头像、姓名/资质与接单开关同一行；今日订单、今日收入、待结算、本月收入用 2×2 独立数据卡；三项待办横排胶囊；三个工具等宽入口；最近订单单行标题/状态、下一行时间/客户。 |
| 服务订单 | 横向滚动状态胶囊，下方为项目/状态、预约/客户、地址、右下收入的白色卡片。详情依次为四节点进度条、客户信息、服务信息、金额明细、状态操作；拒单沿用原单选弹窗。 |
| 排班 | 标题右侧为前后缓冲入口；日期选择、七日条、三态图例、4 列半小时段格；选中时段的原有操作位于格子下方，复制下周置底。占用薄荷、休息浅灰、可接白底绿边。 |
| 收益 / 提现 | 收益顶部三项并列数据卡；明细左信息右金额，负数灰色；底部提现按钮。提现依次为余额、金额与试算、账户选择、提交/记录。余额不大于 1 元时提现入口置灰。 |
| 工具商城 | 分类胶囊、横向商品卡（左侧图标占位、右侧名称/分类/库存/价格）；详情、确认、订单与售后沿用原字段和流程，统一浅色卡片与主次按钮。 |
| 我的 | 浅薄荷身份区、头像与资质；资金管理、个人与服务管理两组列表，每项线性图标、文字和右箭头；原菜单路径全部保留。 |

## 组件与状态

- `App.vue` 统一页面底色、卡片、文字、按钮、输入和胶囊；`uni.scss` 对齐 uview-plus 主色。
- `LinkRow.vue` 为菜单项，线性图标可选，保持原 `path` 跳转；`RejectDialog.vue` 保留原原因和确认事件。
- 金额只突出显示，不改变订单收入、实付与抽成的原字段口径；服务端仍是最终金额和状态权威。
- 原有页面树 27 条路径与四个 Tab 不变。`pages.json` 仅改变导航栏与 Tab 选中色。

## 验收边界

- 当前排班实现是日期 picker + 七日选择与点选/批量按钮，不是 `u-calendar` 或长按浮层。本轮只做视觉重构，没有增加或重写这些交互。
- 待办入口仍沿用原订单列表跳转，当前列表没有 URL 预选状态能力；数据卡也未新增明细跳转。订单完成后凭证按钮仍按原有“服务中”流程呈现。
- 商品 JSON 的图片路径无对应静态资源，当前使用线性图标占位以避免破图。实物图待素材提供后替换，不改变商品结构。
- 类型检查、模拟测试及微信小程序构建可验证源码；微信开发者工具模拟器和真机的视觉、点击热区、长内容换行仍须现场验收。
