# 端内共享能力规划

未来只承载与具体服务者业务无关、确有复用需求的展示与基础能力：通用加载/错误/空态、表单展示、数据格式化、请求错误的公共处理和可复用组件。是否封装 uview-plus、状态方案与目录层级，留待实际工程和兼容性验证后确定。

不把资质审批、排班冲突、超区接单、订单状态、抽成、手续费或商城订单隔离写成共享工具中的“最终判定”。证件、身份证、收款账户、地址和服务凭证属于敏感信息，不在通用日志或缓存里默认留存；权限与脱敏口径须经正式契约确认。不虚构 HTTP 错误码、数据字段或公共运行时跨端包。

当前已有导航、演示横幅和链接行组件；详情见[架构说明](../ARCHITECTURE.md)和[全仓约定](../../../agent.md)。
