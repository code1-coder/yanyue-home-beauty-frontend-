# 平台适配边界规划

当前优先规划独立微信小程序；未来集中适配小程序登录、证件与服务凭证上传/媒体选择、通知、地图导航、电话、商城支付唤起、权限与本地存储。各业务模块依赖平台能力边界，而非直接假定小程序回调、权限和具体渠道行为；目前不建 Android/iOS 工程，但不删减原始 PRD 的兼容及支付范围。

平台登录态不能代替服务端鉴权；上传成功不等于资质审核通过或服务订单完成。导航/电话须遵守敏感信息与授权口径，平台定位不能强制阻止超半径订单。商城支付回跳只可触发服务端状态查询，不凭客户端回调宣称支付成功；原始 PRD 的微信/支付宝支付要求与小程序实施路线须另行确认。

平台层不计算抽成、结算或提现，不把商城订单当作服务订单。当前 `media.ts` 只封装选图、电话和位置导航；选图路径为临时文件，尚无真实上传。具体 API、权限声明、审核要求及可用渠道待产品/技术确认。参见[架构说明](../ARCHITECTURE.md)与[共通规则](../../../docs/common/业务规则与跨端流程.md)。
