## 3. 关键页面原型要点

**首页**
- 顶部：定位（城市+地址，可点击切换）、搜索框、消息铃铛
- 中部：Banner 轮播（u-swiper）、项目分类金刚区（u-grid）
- 下部：推荐项目列表（u-card）、推荐美容师横向滚动
- 底部 TabBar：首页 / 发现 / 我的

**美容师详情页**
- 顶部：头像、姓名、评分、接单数、距离
- 标签：健康证已验、美容师证已验、实名已验
- 服务信息：服务半径、上门费、擅长项目
- 可预约时间：日历 + 半小时段（u-calendar + 自定义时段格）
- 评价列表：u-comment 风格
- 底部固定按钮：立即预约

**预约页**
- 项目信息卡
- 日期选择（未来 7/14 天）
- 时段网格：可约 / 已约 / 休息 三态
- 地址选择（默认地址，可切换）
- 上门费显示（由美容师设置，按距离或固定）
- 备注输入
- 底部：合计金额 + 去支付

**确认订单页**
- 项目金额、上门费、优惠券抵扣、实付金额
- 支付方式：微信 / 支付宝
- 提示：担保交易，平台先收款，服务完成后结算给美容师

**订单详情**
- 状态条 + 进度时间轴：已支付 → 待接单 → 已接单 → 服务中 → 已完成 → 已结算
- 美容师卡片：头像、电话、导航
- 服务信息：项目、时间、地址
- 金额明细：项目实付、上门费、优惠、实付
- 操作：取消、联系、申请退款、评价
