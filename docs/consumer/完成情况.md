# 消费者端完成情况

> 截至 2026-09-26，按 [消费者端原型](原型.md)、[需求](需求.md)与 `apps/consumer` 当前代码核对。本文件记录**模拟前端实现现状**，不是需求验收或上线声明；P0/P1/P2 优先级仍以原始 PRD 为准，[接口能力清单](接口清单.md)仍全部是待设计能力。

## 总体状态

- 已建立 HBuilderX / uni-app Vue 3 / uview-plus 微信小程序模拟工程；`pages.json` 注册了原型清单的 28 个页面路径及首页、发现、我的 TabBar。页面覆盖不等于原型要素和业务能力全部完成。
- 本地样本数据来自 `features/mock/data`，通过 `features/services.ts` 暴露；演示订单、预约草稿、地址和浏览位置使用小程序本地存储。没有后端、正式接口、真实用户身份或跨端数据同步。
- 可演示的主线：浏览项目/美容师 → 选择演示日期、半小时时段及地址 → 查看本地报价 → 创建演示订单 → 选择微信/支付宝**展示渠道**并模拟支付成功或失败 → 查看订单。支付成功只会把本地订单改为“待接单”，没有实际收款或美容师接单、履约、结算闭环。

## 验证与交付边界

- 工程提供 `npm run typecheck`、`npm test`、`npm run build:mp-weixin`；现有单元测试覆盖本地仓储的样本报价、无效时段/地址、位置与地址分离及订单状态变更，不覆盖支付页面交互。详见[消费者端运行说明](../../apps/consumer/README.md)。本次文档核对没有重新执行构建、测试或真机验证。
- README 已记录此前仅完成 CLI 构建、类型和单元测试，尚未验证 HBuilderX 打开效果与真机；不能据此称为已上线小程序。演示素材授权仍须核实，正式发布前替换未获商用授权的图片。
- 正式交付还依赖后端接口契约与鉴权、服务端预约占用/金额/状态校验、支付退款和跨端履约，以及原始需求中的平台适配与支付渠道决策；未决规则见[仓库 README](../../README.md#范围与优先级)和[共通规则](../common/业务规则与跨端流程.md)。
