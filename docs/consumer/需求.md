# 消费者端 · 产品需求

> 摘自 [原始 PRD](../服务产品需求文档（PRD）.md) 第 5 节；保留原文功能与优先级。跨端业务规则参见 [共通规则](../common/业务规则与跨端流程.md)。

## 5.1 消费者端（移动端A）

### 5.1.1 登录注册
| 功能       | 说明                     | 优先级 |
| ---------- | ------------------------ | ------ |
| 手机号登录 | 验证码登录，支持微信登录 | P0     |
| 实名认证   | 可选，下单前可要求       | P1     |
| 位置授权   | 获取定位权限             | P0     |
| 协议       | 用户协议、隐私政策       | P0     |

### 5.1.2 首页
| 功能       | 说明                     | 优先级 |
| ---------- | ------------------------ | ------ |
| 自动定位   | 获取当前位置，可手动切换 | P0     |
| 搜索       | 检索美容项目、美容师     | P0     |
| Banner     | 轮播广告/活动            | P1     |
| 项目分类   | 金刚区分类入口           | P0     |
| 项目列表   | 推荐项目列表             | P0     |
| 美容师列表 | 推荐美容师               | P0     |
| 底部菜单   | 首页、发现、我的         | P0     |

### 5.1.3 美容项目
| 功能     | 说明                             | 优先级 |
| -------- | -------------------------------- | ------ |
| 项目列表 | 分类、筛选、排序                 | P0     |
| 项目详情 | 价格、时长、说明、禁忌、适用人群 | P0     |
| 项目搜索 | 关键词搜索                       | P0     |

### 5.1.4 美容师
| 功能       | 说明                                     | 优先级 |
| ---------- | ---------------------------------------- | ------ |
| 美容师列表 | 按距离/评分/销量排序                     | P0     |
| 美容师详情 | 简介、资质、作品、服务半径、上门费、评价 | P0     |
| 可预约时间 | 展示半小时段可约状态                     | P0     |

### 5.1.5 预约下单
| 功能     | 说明               | 优先级 |
| -------- | ------------------ | ------ |
| 选择时段 | 日历 + 半小时段    | P0     |
| 选择地址 | 地址列表、新增地址 | P0     |
| 上门费   | 按美容师规则计算   | P0     |
| 备注     | 用户备注           | P1     |
| 优惠券   | 选择优惠券         | P1     |
| 确认订单 | 金额明细           | P0     |
| 支付     | 微信/支付宝        | P0     |
| 支付结果 | 成功/失败          | P0     |

### 5.1.6 订单管理
| 功能       | 说明                                       | 优先级 |
| ---------- | ------------------------------------------ | ------ |
| 订单列表   | 状态 Tab                                   | P0     |
| 订单详情   | 状态、美容师、项目、时间、地址、金额、操作 | P0     |
| 取消订单   | 按规则取消                                 | P0     |
| 退款/售后  | 申请退款、上传凭证                         | P0     |
| 联系美容师 | 电话                                       | P1     |
| 导航       | 地图导航                                   | P1     |

### 5.1.7 评价
| 功能     | 说明                   | 优先级 |
| -------- | ---------------------- | ------ |
| 评价     | 星级、文字、图片、匿名 | P0     |
| 我的评价 | 评价列表、追评         | P1     |

### 5.1.8 发现页
| 功能     | 说明                   | 优先级 |
| -------- | ---------------------- | ------ |
| 内容流   | 图文/视频              | P2     |
| 内容详情 | 点赞、收藏、评论、分享 | P2     |

### 5.1.9 我的
| 功能      | 说明                           | 优先级 |
| --------- | ------------------------------ | ------ |
| 个人资料  | 头像、昵称                     | P0     |
| 地址管理  | 增删改查、默认地址             | P0     |
| 优惠券    | 可用/已用/过期                 | P1     |
| 消息中心  | 订单、支付、服务、系统         | P0     |
| 客服/投诉 | 提交投诉                       | P1     |
| 设置      | 缓存、协议、退出               | P1     |
| 安全中心  | 紧急联系人、行程分享、一键求助 | P2     |
