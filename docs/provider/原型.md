# 三、服务者端（美容师端）

## 1. 信息架构树

```
服务者端
├── 登录/入驻
│   ├── 登录页
│   ├── 入驻申请页（实名/健康证/美容师证/个体户）
│   └── 审核状态页
├── Tab1 工作台
│   ├── 工作台首页
│   ├── 排班管理（半小时段日历）
│   ├── 缓冲设置
│   ├── 请假/暂停接单
│   └── 我的项目（可接项目与定价）
├── Tab2 订单
│   ├── 订单列表
│   ├── 订单详情
│   ├── 拒单弹窗
│   └── 服务凭证上传
├── Tab3 商城
│   ├── 商品列表
│   ├── 商品详情
│   ├── 确认订单 / 支付
│   ├── 商城订单列表 / 详情
│   └── 物流 / 售后
├── Tab4 我的
│   ├── 个人资料
│   ├── 资质管理
│   ├── 服务设置（服务半径/上门费）
│   ├── 收益中心

│   ├── 银行卡管理
│   ├── 评价管理
│   ├── 消息中心

```

## 3. 关键页面原型要点

**工作台首页**
- 顶部：头像、认证状态、接单开关（大按钮）
- 数据卡：今日订单、今日收入、待结算、本月收入
- 待办：待接单、待服务、待上传凭证
- 快捷入口：排班、我的项目、提现

**排班管理**
- 日历（u-calendar）
- 选中日期后展示 00:00–23:30 的半小时格
- 每格三态：可接单 / 已占用 / 休息
- 支持点击切换、长按批量、一键复制到下周
- 顶部显示：前缓冲 X 分钟、后缓冲 X 分钟（可跳转设置）

**订单详情（美容师）**
- 状态条
- 用户信息：昵称、电话、地址、导航按钮
- 服务信息：项目、时长、预约时段、备注
- 金额：实付、上门费、平台抽成、预计收入
- 操作：接单 / 拒单 → 开始服务 → 完成服务 → 上传凭证

**收益中心**
- 余额、待结算、累计收入
- 明细列表：订单收入、平台抽成、上门费、退款冲正
- 提现按钮（余额 > 1 元可点）

**提现页**
- 可提余额
- 提现金额输入
- 手续费展示（固定/比例）
- 到账金额 = 提现金额 - 手续费
- 到账账户选择
- 提交
