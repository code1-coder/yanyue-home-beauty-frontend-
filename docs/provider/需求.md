# 服务者端 · 产品需求

> 摘自 [原始 PRD](../服务产品需求文档（PRD）.md) 第 5 节；保留原文功能与优先级。跨端业务规则参见 [共通规则](../common/业务规则与跨端流程.md)。

## 5.2 服务者端（美容师端）

### 5.2.1 登录与入驻
| 功能     | 说明                               | 优先级 |
| -------- | ---------------------------------- | ------ |
| 登录     | 手机号验证码                       | P0     |
| 入驻申请 | 实名、健康证、美容师证、个体户信息 | P0     |
| 审核状态 | 待审核/通过/驳回/重新提交          | P0     |

### 5.2.2 工作台
| 功能     | 说明                       | 优先级 |
| -------- | -------------------------- | ------ |
| 接单开关 | 开启/关闭接单              | P0     |
| 数据概览 | 今日订单、今日收入、待结算 | P0     |
| 待办     | 待接单、待服务、待上传凭证 | P0     |
| 快捷入口 | 排班、我的项目、提现       | P0     |

### 5.2.3 排班管理
| 功能      | 说明                  | 优先级 |
| --------- | --------------------- | ------ |
| 日历排班  | 半小时段设置可接/休息 | P0     |
| 批量设置  | 批量选择              | P1     |
| 复制排班  | 复制到下周            | P1     |
| 缓冲设置  | 前缓冲、后缓冲        | P0     |
| 请假/暂停 | 时间段请假、暂停接单  | P0     |

### 5.2.4 我的项目
| 功能     | 说明         | 优先级 |
| -------- | ------------ | ------ |
| 项目列表 | 平台项目     | P0     |
| 勾选可接 | 选择可接项目 | P0     |
| 设置价格 | 美容师定价   | P0     |

### 5.2.5 订单管理
| 功能      | 说明                                     | 优先级 |
| --------- | ---------------------------------------- | ------ |
| 订单列表  | 状态 Tab                                 | P0     |
| 订单详情  | 用户、地址、项目、时间、金额、抽成、收入 | P0     |
| 接单/拒单 | 接单、拒单原因                           | P0     |
| 开始服务  | 状态变更                                 | P0     |
| 完成服务  | 上传凭证                                 | P0     |
| 导航      | 地图导航                                 | P1     |
| 联系用户  | 电话                                     | P1     |

### 5.2.6 收益与提现
| 功能       | 说明                         | 优先级 |
| ---------- | ---------------------------- | ------ |
| 收益中心   | 余额、待结算、累计收入、明细 | P0     |
| 提现       | 申请提现、手续费展示         | P0     |
| 提现记录   | 状态、到账记录               | P0     |
| 银行卡管理 | 绑定账户                     | P0     |

### 5.2.7 工具商城
| 功能     | 说明             | 优先级 |
| -------- | ---------------- | ------ |
| 商品列表 | 分类、商品卡片   | P1     |
| 商品详情 | 价格、规格、库存 | P1     |
| 下单支付 | 确认订单、支付   | P1     |
| 商城订单 | 列表、详情、物流 | P1     |
| 售后     | 申请售后         | P1     |

### 5.2.8 评价与消息
| 功能     | 说明                   | 优先级 |
| -------- | ---------------------- | ------ |
| 评价管理 | 查看、回复、申诉       | P1     |
| 消息中心 | 订单、审核、提现、系统 | P0     |

### 5.2.9 我的
| 功能     | 说明                       | 优先级 |
| -------- | -------------------------- | ------ |
| 个人资料 | 头像、昵称、简介、擅长项目 | P0     |
| 资质管理 | 证件列表、状态、到期提醒   | P0     |
| 服务设置 | 服务半径、上门费规则       | P0     |
| 设置     | 缓存、协议、退出           | P1     |
