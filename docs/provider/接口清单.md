# 服务者端 · 接口能力清单

## 当前核查结论

- 服务者端前端已完成 27 个页面路由和 4 个底部 Tab：工作台、订单、商城、我的。
- 本清单中的 18 项接口能力均已接入页面入口，并已由 `ProviderServices` 提供 JSON 本地模拟实现，可用于微信小程序端演示和前端联调占位。
- 当前完成的是前端模拟层，不代表正式后端 HTTP 接口已完成。真实联调仍需确认接口 URL、HTTP 方法、请求与响应 DTO、鉴权方式、错误码、分页规则、幂等要求、文件上传协议，以及支付、提现和物流回调等服务端契约。
- 正式接口接入前，页面应继续通过 `ProviderServices` 访问数据，后续替换服务适配层即可，避免页面直接依赖模拟 JSON。

## 关键跨端约束

- 入驻/资质通过管理后台审核后才能接单；证件过期自动暂停接单。
- 排班冲突检测需包含“前缓冲 + 项目服务时长 + 后缓冲”；订单接单/拒单与消费者状态同步。
- 服务订单与工具商城订单相互独立；商城购买不影响接单资格或等级。
- 订单完成后按可配置周期（默认 T+7）结算；余额 **> 1 元** 才可提现，提现须后台审核后打款。参见[共通规则](../common/业务规则与跨端流程.md)。
