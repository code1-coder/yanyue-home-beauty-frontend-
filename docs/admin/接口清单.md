## 关键跨端约束

- 平台统一收款并按订单创建时抽成快照结算；独立抽成优先于默认模板。退款需按退款比例冲正抽成和服务者收入。
- 审核结果、提现打款、退款和订单操作需要留痕并通知对应移动端；角色/数据权限不得由前端单独裁决。
- 原文管理后台技术栈为 **Vue + Element UI**；当前 Web 后台工程规划采用 **Vue 3 + Element Plus**。构建工具、后台服务及接口协议尚未确定；技术规划不修改原始功能与优先级，见[技术选型与仓库结构](../技术选型与仓库结构.md)。
