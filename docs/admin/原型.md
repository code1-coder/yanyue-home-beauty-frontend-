## 3. 关键页面原型要点

**工作台**
- 顶部数据卡：今日订单、今日 GMV、新增用户、待审核数
- 趋势图：订单量、GMV、新增用户
- 待办列表：入驻审核、资质审核、提现审核、退款审核
- 快捷入口

**美容师详情（Tab 结构）**
- 基本资料：头像、姓名、电话、主体类型、服务半径、上门费
- 资质：实名、健康证、美容师证、有效期、审核状态
- 项目：可接项目与价格
- 排班：日历视图
- 订单：历史订单
- 收益：收入、抽成、结算、提现
- 评价：评分与评价列表

**抽成模板**
- 模板名称、抽成比例、适用条件（城市/项目分类/美容师等级）
- 生效时间
- 优先级：独立抽成 > 专属模板 > 默认模板

**系统设置 - 财务规则**
- 结算周期：T+N 可配置
- 提现门槛：>1 元
- 提现手续费：固定 / 比例 / 最低值
- 优惠分摊规则：按项目与上门费比例分摊
- 退款抽成冲正规则
