# 管理后台 · 产品需求

> 摘自 [原始 PRD](../../服务产品需求文档（PRD）.md) 第 5 节；保留原文功能与优先级。跨端业务规则参见 [共通规则](../common/业务规则与跨端流程.md)。

## 5.3 管理后台

### 5.3.1 工作台
| 功能     | 说明                                   | 优先级 |
| -------- | -------------------------------------- | ------ |
| 数据概览 | 今日订单、GMV、新增用户、待审核        | P0     |
| 趋势图   | 订单量、GMV、用户                      | P1     |
| 待办     | 入驻审核、资质审核、提现审核、退款审核 | P0     |

### 5.3.2 审核中心
| 功能           | 说明                   | 优先级 |
| -------------- | ---------------------- | ------ |
| 服务者入驻审核 | 查看资料、通过/驳回    | P0     |
| 资质审核       | 实名、健康证、美容师证 | P0     |
| 提现审核       | 打款、驳回             | P0     |
| 退款/售后审核  | 同意/拒绝              | P0     |

### 5.3.3 用户管理
| 功能       | 说明             | 优先级 |
| ---------- | ---------------- | ------ |
| 消费者列表 | 搜索、详情、封禁 | P1     |
| 消费者详情 | 订单、评价       | P1     |

### 5.3.4 服务者管理
| 功能         | 说明                                     | 优先级 |
| ------------ | ---------------------------------------- | ------ |
| 美容师列表   | 搜索、状态、服务半径、上门费             | P0     |
| 美容师详情   | 资料、资质、项目、排班、订单、收益、评价 | P0     |
| 独立抽成     | 设置独立抽成比例                         | P0     |
| 奖惩/禁用    | 禁用、奖励                               | P1     |
| 资质到期提醒 | 列表与提醒                               | P1     |

### 5.3.5 项目管理
| 功能     | 说明                     | 优先级 |
| -------- | ------------------------ | ------ |
| 项目分类 | 增删改查                 | P0     |
| 项目列表 | 编辑、价格、时长、上下架 | P0     |

### 5.3.6 订单管理
| 功能      | 说明                         | 优先级 |
| --------- | ---------------------------- | ------ |
| 订单列表  | 多条件筛选、导出             | P0     |
| 订单详情  | 状态、金额、抽成、日志、改派 | P0     |
| 改派      | 更换美容师                   | P1     |
| 退款/售后 | 处理                         | P0     |

### 5.3.7 排班调度
| 功能     | 说明         | 优先级 |
| -------- | ------------ | ------ |
| 排班查看 | 美容师时间池 | P1     |
| 冲突处理 | 冲突标记     | P1     |

### 5.3.8 抽成管理
| 功能     | 说明                         | 优先级 |
| -------- | ---------------------------- | ------ |
| 抽成模板 | 默认比例、适用条件、生效时间 | P0     |
| 独立抽成 | 美容师ID、覆盖比例、生效时间 | P0     |

### 5.3.9 财务管理
| 功能     | 说明                 | 优先级 |
| -------- | -------------------- | ------ |
| 支付流水 | 查询、导出           | P0     |
| 结算单   | 结算周期、明细、状态 | P0     |
| 提现审核 | 审核、打款           | P0     |
| 退款记录 | 查询                 | P0     |
| 对账     | 平台与支付渠道对账   | P1     |

### 5.3.10 营销管理
| 功能          | 说明             | 优先级 |
| ------------- | ---------------- | ------ |
| 优惠券        | 创建、发放、统计 | P1     |
| 活动          | 配置活动         | P2     |
| Banner/推荐位 | 图片、跳转、排序 | P1     |

### 5.3.11 内容管理
| 功能       | 说明               | 优先级 |
| ---------- | ------------------ | ------ |
| 发现页内容 | 发布、编辑、上下架 | P2     |
| 评论审核   | 审核、删除、敏感词 | P2     |

### 5.3.12 评价管理
| 功能      | 说明       | 优先级 |
| --------- | ---------- | ------ |
| 评价列表  | 查看、审核 | P1     |
| 投诉/申诉 | 处理       | P1     |

### 5.3.13 工具商城
| 功能     | 说明                     | 优先级 |
| -------- | ------------------------ | ------ |
| 商品管理 | 编辑、价格、库存、上下架 | P1     |
| 库存管理 | 库存变动                 | P1     |
| 商城订单 | 订单、发货、物流         | P1     |
| 物流管理 | 发货、物流跟踪           | P1     |
| 售后     | 售后处理                 | P1     |

### 5.3.14 消息通知
| 功能     | 说明     | 优先级 |
| -------- | -------- | ------ |
| 推送     | 推送消息 | P1     |
| 短信模板 | 模板管理 | P1     |
| 站内信   | 发送记录 | P1     |

### 5.3.15 数据统计
| 功能       | 说明       | 优先级 |
| ---------- | ---------- | ------ |
| 经营概览   | 核心指标   | P1     |
| 订单统计   | 订单维度   | P1     |
| 用户统计   | 用户维度   | P1     |
| 美容师统计 | 美容师维度 | P1     |
| 区域热力   | 区域分布   | P2     |

### 5.3.16 系统设置
| 功能              | 说明                       | 优先级 |
| ----------------- | -------------------------- | ------ |
| 角色权限          | 角色、菜单、数据权限       | P0     |
| 菜单管理          | 菜单配置                   | P1     |
| 操作日志          | 查询、导出                 | P1     |
| 城市/距离配置     | 城市、距离                 | P1     |

| 优惠分摊规则      | 项目与上门费分摊           | P0     |
| 协议/隐私         | 协议管理                   | P1     |
